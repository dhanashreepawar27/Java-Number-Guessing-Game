# Java Number Guessing Game

A simple number guessing game developed using Java.

## About the Project

The computer generates a random number between 1 and 100. The player tries to guess the number using hints provided by the program.

## Features

- Generates a random number between 1 and 100.
- Accepts guesses from the user.
- Displays hints when the guess is too high or too low.
- Counts the number of attempts.
- Displays a winning message.

## Technologies Used

- Java
- Scanner class
- Random class
- Loops and conditional statements

## How to Run

1. Download or clone this repository.
2. Open `NumberGuessingGame.java` in a Java development environment.
3. Compile the program:

   `javac NumberGuessingGame.java`

4. Run the program:

   `java NumberGuessingGame`

## Learning Outcomes

This project demonstrates basic Java programming concepts, including user input, random number generation, conditional statements, loops, and counters.
